# Youguard Academy — 内容创作规范 v1.0

> 最后更新：2026年5月17日

---

## 一、Academy的定位和目标

### 与Insights的区别

| | Insights | Academy |
|---|---|---|
| **内容性质** | 市场资讯、政策解读、行业分析 | 操作指南、技能培训、实务手册 |
| **读者状态** | 做决策前查阅 | 执行过程中参考 |
| **时效性** | 部分内容有时效（热点响应型） | 以常青为主，更新频率低 |
| **文章结构** | 分析+观点+来源 | 步骤+工具+注意事项 |

### Academy的核心受众

**经销商老板/管理者：**
转型期中小经销商，有ICE销售背景，正在学习EV产品知识和销售方法。时间有限，需要能直接用于业务决策的内容。

**一线销售人员：**
需要能应对客户问题的话术和知识框架，不需要深度技术细节。

**技师/维修人员：**
有一定ICE维修基础，正在学习EV特有的系统和故障诊断方法。对安全规程重视度需要主动提升。

## 二、三大内容分类

### EV Fundamentals（EV基础知识）
> 目标：让经销商和销售人员理解EV的核心工作原理，足以自信地与客户沟通

**适合的选题：**
- EV核心概念：电池化学、续航机制、充电原理
- 与ICE的本质差异（对销售和维修都有用）
- 非洲/埃塞俄比亚特殊条件对EV的影响

**不适合的选题：**
- 过于基础的科普（"什么是电动车"）
- 只有工程师才需要的深层技术细节
- 与非洲市场无关的全球通用概念（太多竞争对手会写）

**文件夹：** `ev-fundamentals/`

---

### Dealer Playbook（经销商运营手册）
> 目标：帮助经销商在销售、大客户开发、定价管理和日常运营四个方向提升能力

**四个子方向（选题时按此分类）：**

| 子方向 | 核心问题 | 目标读者 |
|---|---|---|
| Sales Conversion（销售转化） | 如何把进店客户转化为成交 | 销售人员 |
| Fleet & B2B（大客户） | 如何开发出租车协会、企业、NGO | 老板/销售 |
| Pricing & Financial（定价财务） | 如何在汇率波动中保护利润 | 老板 |
| Operations & Growth（运营增长） | 如何提升售后满意度和口碑 | 老板 |

**文件夹：** `dealer-playbook/`

---

### Technical Workshop（技术工坊）
> 目标：帮助技师掌握中国品牌EV的安全操作、诊断和常见故障处理

**选题原则：**
- 优先覆盖非洲/埃塞俄比亚特定条件下的故障规律
- 安全类内容必须符合国际标准（IEC/GB/T），不可简化或省略
- 通用原理优先于品牌/车型专属内容（避免依赖未公开的OEM文件）

**文件夹：** `technical-workshop/`

## 三、文章质量标准

### 严谨性红线（违反则重写）

Technical Workshop类：
- ✗ 引用品牌专属服务手册中的具体数据，但该手册未公开
- ✗ 将适用于某一车型的操作步骤写成通用步骤（须注明"以[车型]为例"）
- ✗ 将编辑估算的数值（如维修费用范围）写成官方数据
- ✗ 描述高压操作步骤时省略安全前提

Dealer Playbook类：
- ✗ 引用虚构的市场调研数据
- ✗ 将个别案例写成普遍规律
- ✗ 承诺具体的销售转化率或ROI数字（属于无法核实的具体断言）

EV Fundamentals类：
- ✗ 将实验室测试规格（WLTP）直接等同于真实驾驶表现
- ✗ 将通用技术趋势写成已在非洲市场落地

### 时效性标注规则

含以下信息的文章，必须在Sources后加时效提示：
- 燃油/电费价格（ETB计价）
- 进口关税税率
- 政策法规状态
- 货运报价

格式：
```
*本文[数据类型]基于[来源/采集日期]整理。建议在执行前向[相关机构]确认当前有效数据。*
```

## 五、字数规范

| 文章类型 | 字数范围 | 说明 |
|---|---|---|
| 操作步骤类（Technical Workshop） | 1,500–2,500字 | 步骤须完整，不可为控制字数而省略关键步骤 |
| 销售知识类（Dealer Playbook） | 1,200–2,000字 | 可以更简洁，重点在实用性 |
| 基础知识类（EV Fundamentals） | 1,200–2,000字 | 避免过度科普，以非洲应用场景为锚 |

## 六、SEO要求

每篇文章上线前确认：

| 项目 | 要求 |
|---|---|
| 核心关键词 | 出现在：标题、Overview第一句、至少一个H2、Tag字段 |
| URL slug | 与文章文件夹名一致，全小写，连字符分隔 |
| Meta description | 150字以内，含核心关键词，描述文章对读者的价值 |
| 图片alt文本 | 描述图片内容，不写纯装饰性描述 |
| 内链 | 每篇至少引用1篇相关Academy或Insights文章 |

## 七、配图规范

### 文章图片原则

Academy文章目前仅使用每篇一张hero图（`hero.jpg`）。技术流程图、系统架构图等说明性配图，在具备设计支持后再系统性补充。

### hero图类型指引

| 分类 | hero图风格 |
|---|---|
| EV Fundamentals | 场景化：EV在非洲环境中使用，或技术概念的视觉呈现 |
| Dealer Playbook | 人物场景：销售对话、客户互动、经销商工作场景 |
| Technical Workshop | 操作场景：技师在工坊工作，工具和设备可见 |

### 配图生成Prompt格式

```
[主体场景], [地理/文化背景（如East Africa, Addis Ababa, Ethiopian workshop）], 
[光线/氛围], professional commercial photography, sharp focus, no text
```

## 八、来源规范（同Insights，简化版）

**一级来源（直接引用）：**
IEC/ISO国际标准、中国国标（GB/T）、各国政府机构官方数据

**二级来源（注明来源报道）：**
CATL、BYD、MG等品牌公开发布的技术文件；NREL、IEA、BloombergNEF等研究机构报告

**三级来源（需交叉验证）：**
行业媒体报道（CnEVPost、EV24.Africa、Reuters等）——同一事实需2个独立来源

**四级（编辑估算）：**
费用范围、时间估算、维修周期等无官方来源的数字——文中须注明"编辑估算"

**绝对禁止：**
- 引用品牌未公开的专属服务手册数据作为通用数据
- 将适用于某一车型的参数写成全品类通用参数（未注明车型）
- 虚构机构名称

## 九、人工审稿标准

| # | 维度 | 通过标准 |
|---|---|---|
| 1 | **严谨性** | 无未注明的精确估算数字；操作步骤的前提条件清晰 |
| 2 | **实用性** | 读者读完能直接用：至少有1个具体步骤、数字或话术示例 |
| 3 | **专业感** | 像有经验的同行写给同行，不像通稿或AI腔 |
| 4 | **SEO** | 标题和Overview第一句含核心关键词 |

4项全过 → ✅ 发布  
任意1项不过 → 📝 退回修改
