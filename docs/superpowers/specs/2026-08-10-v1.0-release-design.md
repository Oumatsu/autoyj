# 1.0.0 Release Verification & Deployment Design

## Overview
This design document defines the final quality gates, commit conventions, tag strategy, push workflow, and GitHub Actions / Cloudflare deployment verification for autoyj version 1.0.0.

## Key Changes in 1.0.0
1. **i18n & Tolgee Architecture**:
   - Normalized single-field heading translations using standard `<theme>` and `<accent>` rich text tags.
   - Synchronized tag counts and positions across Chinese (`zh.json`), English (`en.json`), and Amharic (`am.json`).
   - Replaced legacy `<accent1>` / `<accent2>` tags with unified design system tokens.

2. **D1 Database Sync Stability**:
   - Added `batchStatements` chunking helper in `server/api/portal.ts` (max 100 statements per chunk).
   - Prevents Cloudflare D1 `Batch size limit exceeded` failures (>120 statements limit).
   - Ensures full synchronization of 100 vehicle models, 610 trims, and 657 inventory records from Feishu Bitable into D1.

3. **Asset & Image Integrity**:
   - Mapped all vehicle and insight images to verified `/pic/` assets.
   - Guarded against fallback image overuse and orphan data.

4. **Test Suite Coverage (860 Tests Total)**:
   - Unit Tests: 415 tests (100% pass)
   - Component Tests: 103 tests (100% pass)
   - Integration Tests: 46 tests (100% pass)
   - E2E Playwright Tests: 296 tests across 3 locales (100% pass)

## Verification Pipeline
Before committing and pushing, the release task executes the following automated checks:
1. `bun run check:i18n` — Validate translation keys and formatting.
2. `bun run test` — Run unit, component, and integration test suites.
3. `bun run test:e2e` — Execute full Playwright E2E browser tests.

## Release Commit & Tagging Protocol
- Commit message: `release(v1.0.0): prepare 1.0 release`
- Tag: `v1.0.0`
- Target branch: `main`
- Post-push action: Monitor GitHub repository & Actions via `gh` CLI (`gh run list`, `gh release view v1.0.0`).

## Deployment Status Check
After `git push origin main --tags`, verify:
- `gh run list --limit 5` to confirm CI build and Cloudflare deployment success.
