# Issue tracker

## System

This repository uses GitHub Issues in `joyspace-work/autoyj`.

Use the GitHub CLI for issue operations:

```bash
gh issue list --repo joyspace-work/autoyj
gh issue view <number> --repo joyspace-work/autoyj
gh issue create --repo joyspace-work/autoyj
```

Issue URLs should use the repository's GitHub issue tracker. Keep issue titles and descriptions focused on one actionable piece of work, and link related pull requests from the issue when applicable.

## Pull requests

Pull requests are not treated as a separate request surface for triage by default. Use GitHub Issues for incoming work unless the repository owner changes this policy here.
